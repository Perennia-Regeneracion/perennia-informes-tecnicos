# Prueba guiada con una cuenta individual de ChatGPT

La prueba empieza después de instalar el plugin en ChatGPT web o de escritorio y conectar el MCP habitual de Plataforma. Termina con un borrador revisable; no publica ni envía datos a productores.

1. **Instalación:** en una cuenta individual de técnico, cargar el ZIP en ChatGPT web o agregar el marketplace local en escritorio según [INSTALACION-LOCAL.md](../INSTALACION-LOCAL.md). Confirmar que aparece **Informes Perennia** y que incluye el conector de Plataforma. Si la cuenta web rechaza el ZIP, registrar el mensaje exacto.
2. **Autenticación:** conectar Plataforma con la cuenta personal del técnico. En Work, seleccionar el plugin y pedir `mis_capacidades` con `{"modo":"resumen"}`. Registrar respuesta real o error exacto.
3. **Datos:** buscar un establecimiento conocido y leer un plan o una grabación que ya consultes normalmente en Plataforma. Verificar que la cuenta y el hub son los tuyos; si una lectura falla, registrar el error y trabajar con el material disponible.
4. **Borrador:** pedir un DI, PA o PC de prueba. Revisar procedencia de cada cifra, identidad del campo y técnico, servicio, campaña, fechas, unidades, logo del nodo y dudas abiertas.
5. **Formato propio:** adjuntar un informe anterior del mismo técnico como referencia de estilo; verificar que no se copian datos ni conclusiones del campo modelo. Si quiere reutilizar ese formato en otro chat, guardar el modelo y la ficha de perfil en las fuentes de su Proyecto.
6. **Resultado:** registrar tipo de informe, paso fallido, mensaje de error y cambios que el técnico pide. No usar datos reales de productores en tickets públicos.

La validación de archivos del repositorio no sustituye esta prueba en ChatGPT.
