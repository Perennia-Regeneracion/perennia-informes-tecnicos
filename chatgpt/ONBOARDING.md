# Prueba guiada en ChatGPT

La prueba termina con un borrador revisable; no publica ni envía datos a productores.

1. **Importación:** comprobar que el marketplace con Path `chatgpt` importa `perennia-informes` sin etiqueta **Desktop only** y que las cuatro skills están disponibles.
2. **Autenticación:** cada técnico conecta `conector-plataforma` con su cuenta. En Work, selecciona plugin y app, y pide `mis_capacidades` con `{"modo":"resumen"}`. Registrar respuesta real o error exacto.
3. **Permisos:** buscar un establecimiento autorizado. Verificar que se puede leer ese caso y que uno fuera de su ámbito no se expone. No usar datos de otro técnico para completar huecos.
4. **Borrador:** pedir un DI, PA o PC de prueba. Revisar procedencia de cada cifra, identidad del campo y técnico, servicio, campaña, fechas, unidades, logo del nodo y dudas abiertas.
5. **Formato propio:** adjuntar un informe anterior del mismo técnico como referencia de estilo; verificar que no se copian datos ni conclusiones del campo modelo. Si quiere reutilizar ese formato en otro chat, guardar el modelo y la ficha de perfil en las fuentes de su Proyecto.
6. **Resultado:** registrar tipo de informe, paso fallido, mensaje de error y cambios que el técnico pide. No usar datos reales de productores en tickets públicos.

La validación de archivos del repositorio no sustituye esta prueba en ChatGPT con una cuenta de técnico.
